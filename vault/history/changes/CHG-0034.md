# CHG-0034

CONV0023 순차 요구로 기존 LOG03/04의 메모·머신/ROM 조건을 구현했다. 이전에는 입력/구분할 수 없었고 이제 선택 저장/추이·이전값 분리·세트 적용이 가능하다. 상세와 검사·정책은 [계약](../../wiki/operations/record-details.md), [원본](../../raw/research/2026-10-05-record-details-loop.json), [PRD0.9.2 전체](../versions/prd-v0.9.2.md).

추가로 strict 서버 schema의 과거 선택 필드 미지원 오류를 재현했다. prepared validator migration은 client/서버 계약 drift를 고정하지만 자동 승인 검토가 영구 DDL의 명시 승인을 요구해 적용/의존 배포는 대기 중이다. local 구현과 실제 운영 전송을 구분한다. 이전198불변 파일은 유지했다.

한도 후 재개 요청에 따라 초기화 뒤03:00 KST 일회 조건부 heartbeat를 도구로 등록했다. 이 시점 quota는 허용 상태이며 실제 한도 중단 여부를 확인한 후에만 재개한다. 인간 SQL 승인을 시간/예약으로 대체하지 않는다. 앱/schema/backup 번호와 기존 과학/기기/파일럿/P2 관문은 유지한다.

PRD/진행/백로그/남은 작업/미결/Supabase·볼륨 상세·하네스/루프·운영/인덱스·README/AGENTS에 반영했다. 사용자 요구와1000/80자·문자열 비교 등 구현 정책을 구분한다.
