# CHG-0003 PWA 채택과 언어·데이터 저장 제안

2026-10-03, Asia/Seoul. **0.2.0 → 0.2.1**. 기존 설치 방향의 채택·기술 상세 제안 구체화로 PATCH 변경. 새로운 클라우드 기능이 사용자 승인된 것으로 기록하지 않는다. [원문](../../raw/conversations/2026-10-03-003.md) · [대화](../../wiki/conversations/2026-10-03-003.md).
