# CHG-0002 iOS·개인 사용 범위와 설치 의견 반영

## 남은 사항과 검증

PWA 채택·지원 OS·건강 앱/Watch·경험/루틴·백업/동기화·예산 미확정. 운동·식단 기능 의도는 유지한다. 구독·출시 단계·로컬 계정 생략을 사용자 승인으로 올리지 않는다.

구조·링크·출처 메타데이터·원본 해시는 `ruby scripts/validate_vault.rb`로 검사하며 실행 결과는 [검증 보고서](../validation-latest.json)에 남긴다. 이 변경 기록은 검사 전에 작성한 불변 기록이다. 실제 앱/실기기·Apple 계정/배포 시험과 운동 연구 전문 검토는 수행하지 않았다.
