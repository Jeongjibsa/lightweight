# CHG-0031

## 사용자 발언과 이유

CONV0021 원문은 “다음 운동 후 확인”이다. 실제 운동 저장→재실행→수동 클라우드 전송 결과 요청에 대한 확인 시점의 답변이다. 수행 결과나 구체 날짜는 보고되지 않았다.

## 변경 전후

이전에는 결과 요청 후 응답 대기였다. 현재는 다음 운동 이후 사용자 확인 예정으로 기록하고 실제 검증 상태는 not_run으로 유지한다. 체크리스트에서 수동 전송과 새 저장소 적용을 각각 분리하여, 후자까지 다음 운동에 확인하겠다는 승인으로 확대하지 않는다. 홈 화면 설치·실행·로그인의 기존 사용자 보고 완료는 유지한다.

[PRD](../../wiki/product/prd.md)·[전체 스냅샷](../versions/prd-v0.8.16.md)·[진행](../../wiki/product/implementation-progress.md)·[백로그](../../wiki/product/implementation-backlog.md)·[남은 작업](../../wiki/product/remaining-work.md)·[미결](../../wiki/product/open-questions.md)·[실사용 체크리스트](../../wiki/operations/iphone-pilot-checklist.md)에 반영했다. 대화 원문/요약·관련 index·log를 추가했고 이전177개 불변 파일은 보존했다.

## 미결 사항과 검증 범위

실제 저장·재실행·전송 결과는 사용자 확인 뒤 새 이력에 기록한다. 새 저장소 복원·실Auth A/B/만료·나머지 iPhone 접근성/보존·운영 복구·과학/자산 검토·실제4주 파일럿 등은 유지한다. 이번 변경은 문서이며 앱 코드·배포를 변경하지 않는다. 개발 전체 중단이나 알림 생성 요청으로 해석하지 않는다.
