# CHG-0023

|---|---|
| 계정1/허용0, 대상/방식 승인 pending | 명시 승인 후 계정1/허용1·enabled 확인 |
| 실제 앱 Auth 미확인 | 사용자 Chrome 로그인됨·계정 DB 관찰 |
| 실제 전송 미확인 | 운동/루틴0개 빈 기본 프로필 저장 ACK/revision1→조회/명시 같은 기기 적용·대기0/복구 수단 확인 |
