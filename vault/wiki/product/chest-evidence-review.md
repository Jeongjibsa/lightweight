# 가슴 운동 조건별 검토 패킷

**상태: 에이전트 검토 초안 / 실제 승인0 / 운영 제공하지 않음.** 사용자는 남은5 근거 운동 정보를 우선 요청했다. 아래 종목 선택과 검토 순서는 기획자의 구현 제안이며 전문가 승인이나 보편 순위가 아니다.

## 한 부위부터 검토할 비교 조건

목표는 근비대, 장비는 실제 연구 장비/사용자 가용 장비를 구별한다. 경험·불편감·가동범위·시간이 미입력이면 개인 적합도는 보류한다. 직접 비교 없는 후보를 낮은 티어로 내리지 않고 ‘비교 자료 부족’으로 둔다.

| 후보 | 현재 확보한 자료와 적용 상태 | 다음 검토 |
|---|---|---|
| 스미스 평벤치/44°인클라인 | SRC054의 해당 조건 직접 비교; 문구 승인 전 | 방법론/누락/측정 위치·외적 타당성·공개 문구 확인 |
| 바벨 벤치 프레스 | 연구 장비가 달라 그대로 승인하지 않음 | 자유 바벨 장기 비교/수행·해부학 출처 확보 |
| 덤벨 벤치/덤벨 인클라인 | 이번 연구로 직접 티어 판단 불가 | 덤벨 조건별 장기 자료/안정화 역할 구분 |
| 딥스 | 이번 표적 검토에서 직접 비교 확보 못함 | 해당 변형/가동범위·설명·권리 검토 |
| 머신 체스트 프레스 | 기구 모델을 하나로 추정하지 않음 | 모델/동작 조건과 연구의 대응 확인 |

## 인간 검토를 받을 문구와 결정

- CLAIM-CHEST-ANGLE-01 후보: ‘벤치 각도 비교 결과는 연구에서 사용한 장비·각도·대상과 측정 위치를 함께 봐야 합니다.’ SRC054의 상세 근거/읽은 범위는 출처 노트에 한 번 보존했다. 운영 공개 여부/수정 문구를 운동과학 검토자가 결정한다.
- MAP-CHEST-01: 연구 측정 위치를 직접/간접 세트 가중치로 변환하지 않는다. 주/보조/안정화 역할의 해부학 근거와 중복 집계 정책은 별도 검토 전이다.
- TIER-CHEST-01: 위 후보의 S/A/B 순위를 아직 산출하지 않는다. 효과의 직접 비교·근거 확실성·개인 적합도 세 축과 ‘보류’를 구분하는 정책을 검토한다.
- RULE-CHEST-01: 개인 권장 세트/증량은 아직 없음. 현재 보고서는 기록량만 관찰하고 목표·주간 일정은 사용자 설정을 그대로 표시한다.

## 공개할 때 필요한 구체 자료

선정 주장별 인간 검토자의 전문 영역·검토일·검토 reference·정확한 payload SHA256, 적용 대상/한계/출처를 받아 registry에 넣는다. 자료 수정 시 재검토한다. 2D 근육 지도는 주/보조 역할을 텍스트로 함께 표현하고 이미지 권리/alt/파일 hash가 준비된 뒤 공개한다. 3D는 기존P2다. 이번에는 논문 그림을 복제하거나 인간 reviewer receipt를 만들지 않았다.

ACSM2026 기존SRC003의 공식 발행 안내를 재확인했으나 전문은 도구에서 읽지 못했다. 초록을 전문으로 올리거나 수치 임계값을 자동 권장량으로 채택하지 않았다. [접근/읽은 범위](../../raw/research/2026-10-08-chest-review-capture.json).
