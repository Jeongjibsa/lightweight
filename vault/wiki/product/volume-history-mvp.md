# 볼륨·추이·오늘의 기록 기반 후보 MVP

FR-14/15, CONV-0009. [원문](../../raw/conversations/2026-10-04-009.md). **관찰 계산→추이→기록 참고 후보→검토된 운동량 조정**의 단계로 운동 MVP에 추가한다. 식단은 후속을 유지한다. 아래 정규화/비교/충분성 상세는 구현자가 선택한 정책이며 과학적 최적값이 아니다.

## 1. 볼륨의 의미와 표시

| 지표 | MVP 계산 | 제외/표시 |
|---|---|---|
| 완료 본세트 | 완료한 working 입력 행 | warmup·미완료·취소/삭제 session 제외. active의 완료 행은 일별 관찰에 포함 |
| 반복수 | 포함한 완료 본세트의 reps 합 | timed는 반복 없음; 좌우 별도 행 각각 집계 |
| 시간 | timed 완료 본세트 seconds 합 | 중량 볼륨에 합치지 않음 |
| 총 중량 기록량 | total mode의 Σ(toKg(load)×reps), kg·회 | kg/lb 정규화. N/A와 실제0을 구분 |
| 운동별 기록 볼륨 | 같은 운동 snapshot·장비 문자열·loadMode·side의 Σ(toKg(load)×reps) | per_hand는 한 손 기준으로 유지하고 임의×2 하지 않음. machine은 표시 중량 참고. 맨몸/보조/시간은 중량 볼륨 N/A |
| 일별 요약 | 해당 localDate의 세트·반복·시간, total mode 부분합·포함행/전체행 | 모든 운동을 하나의 생리적 부하/성장 점수로 합치지 않음. 포함 범위/다른 방식 표시 |

종목 비교 key는 ID·이름·group·장비·mode·좌우를 포함한다. 같은 ID라도 이름/조건 변경 시 별도 계열이다. 단위만 다르면 kg로 정규화한다. 동일 장비 문자열만으로 실제 같은 머신/가동범위를 증명하지 못하므로 사용자 확인 안내를 둔다. ROM/머신 식별자 기록은 후속 계약이다.

계산은 현재 owner를 명시해 타인 자료를 제외한다. 수정/완료취소·삭제·백업 복원 후 live 데이터로 재계산하고 별도 오래된 집계 DB를 만들지 않는다. 시작 당시 localDate/timeZone을 보존한다. 미래 날짜는 현재 화면/오늘 후보에서 제외한다. 계산 버전 `record-volume-v1`을 표시한다.

## 2. 그래프와 과업

리포트에 ‘일별 전체’/‘같은 운동 조건’을 선택하고 28/84일 또는 전체 기간으로 확인한다. 세트·반복·시간·기록 볼륨을 전환한다. 그래프 X는 실제 날짜 간격이고 기록 없는 날은 0으로 만들지 않는다. 볼륨 N/A는 선을 끊고 결측을0으로 찍지 않는다. 유효 한 점은 점만 표시하고 변화율은 비교값/기준0에서 보류한다.

그림과 함께 날짜·세트·반복·시간·볼륨/포함 범위의 표를 제공해 색/hover에만 의존하지 않는다. 작은 화면에서 선택/단위/표 조작이 가능해야 한다. 하루 여러 세션은 같은 날짜/조건으로 합치되 최신 완료 세션 참고는 session별로 남긴다. 0/결측·kg/lb·좌우·시간·조건 변경·준비/삭제·다른 계정·기간/날짜 간격을 독립 표본으로 검사한다.

## 3. 오늘의 후보와 권장 볼륨의 단계

**MVP 1차 — 사용자 루틴/과거 기록 참고:** 사용자 설정과 현재 장비에 맞는 본인 루틴 중 최근 완료 순서를 참고해 후보를 보여준다. 최근28일의 종료된 complete/partial 세션만 사용하고 오늘 이미 수행했거나 진행 중이면 추가 자동 후보를 보류한다. 설정/자료/루틴이 부족하면 직접 선택/기록을 안내한다. 실제 장비 항목과 매칭되지 않는 custom 장비는 후보에서 보류한다.

후보의 현재 계획 세트와 같은 루틴의 최근 ‘실제 완료 본세트 수/날짜·운동별 기록량’을 나란히 보여준다. partial은 일부 완료로 표시한다. 후보는 자동 시작/루틴 수정하지 않고 사용자가 선택해야 적용된다. 과거 설정과 목표/분할/장비가 바뀐 기록은 후보 근거에서 제외한다. 기간과 제외 이유/규칙 버전을 표시한다. 부위 회복 완료·성장/최적 용량·근거 검토된 새로운 종목 처방으로 표현하지 않는다.

**MVP 2차 — 검토된 권장 운동량:** SCI-03/REP-03에 최근 수행·계획·노력/RIR·불편감·충분성·동일 조건을 연결하고 유지/조정 범위·이유/보류·근거/규칙 버전을 제공한다. 현재 불편감/경험/ROM 자료와 정책 검토가 부족해 자동 증량이나 세트 처방은 아직 제공하지 않는다. 기록 톤수 증가만으로 근육 성장/회복/증량 필요를 판단하지 않는다. 새 운동 추천은 검토된 콘텐츠 registry를 통과한 종목부터 한다.

## 근거와 읽은 범위

[2026 ACSM Position Stand](https://pmc.ncbi.nlm.nih.gov/articles/PMC12965823/)의 Discussion 관련 단락을 표적 읽었다. 논문은 volume-load가 포함 리뷰에서 드물게 다뤄졌고 개인별 최적 세트 수 확정과 개별화에 한계가 있음을 설명한다. 이 때문에 **기록량 추이를 성장/최적 처방으로 해석하지 않는 제품 판단**을 적용한다. 전체 방법/보충자료·편향의 전문 검토를 완료한 것은 아니다.
