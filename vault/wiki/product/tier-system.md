# 조건별 운동 티어 정책

FR-04. ‘현재 조건에서 이 목표를 위해 우선 고려할 운동은?’에 답한다. [기획서](prd.md).

## 분리할 판단

| 요소 | 기준 | 표시 |
|---|---|---|
| 연구 효과 | 비교 조건·장기 결과·직접성·불확실성 | 확인된 결과와 대상 |
| 실용성 | 장비·증량·학습 요구·시간 | 선택 이유·대체안 |
| 개인 적합도 | 목표·일정·선호·제약·기록 | 현재 조건의 추천 티어 |

S/A/B/C와 연구 근거 배지를 분리한다. 근거 배지는 자체 검토 라벨이며 정식 GRADE 판정과 구별한다. 직접 비교가 없으면 동등 후보/평가 보류를 허용한다.

## 등급 제안

- S: 현재 조건에서 우선 후보. 필수 조건을 충족하고 우선할 이유가 있다.
- A: 좋은 대안. 목표 달성에 적절하다.
- B: 특정 조건·보완 목적에 유용하다.
- C: 현재 조건에서 우선도가 낮다. 이유를 표시한다.
- 평가 보류: 근거/검토/개인 조건이 부족하다.

적용 불가 조건은 C로 숨기지 않고 후보에서 제외하여 이유를 알려준다. 초기에는 사람이 검토한 규칙 표를 사용하며 미검증 가중치 점수는 사용하지 않는다.

## 평가 절차와 예시

목표·부위·숙련도·장비 고정 → 적용 불가 제외 → 검토된 주장 확인 → 시간/학습/선호 평가 → 등급/이유/버전 저장. 개인 피드백은 적합도에 반영하되 연구 결과를 바꾸는 근거로 사용하지 않는다.

| 맥락 | 가능한 설명 | 제한 |
|---|---|---|
| 삼두 근비대·케이블·머리 위 자세 가능 | 오버헤드 후보의 직접 비교 연구가 있다 | 단일 연구를 자동 S 티어로 바꾸지 않음 |
| 둔근 근비대·스쿼트/힙 스러스트 | 목표·장비·다른 부위 훈련 필요로 선택 | 개인 성장의 동등성/절대 우위 보장 불가 |
| 새 머신 | 장비 적합도·검토 상태 설명 | 근비대 우위 평가 보류 |
