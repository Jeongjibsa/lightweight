# 연구 근거 수집과 검토 정책

연구 결과·제품 적용 판단·임시 정책을 구분한다. 최신 연도만으로 더 직접적인 기존 근거를 대체하지 않는다. 자체 편집 정책이며 정식 GRADE 평가는 아니다.

## 수집과 검토

SRC ID·제목·저자·DOI/PMID·공식 URL·온라인/권호일·유형·대상·개입/비교·결과·한계·읽은 범위·검색일·주장·추가 검토. 프리프린트/정식 DOI를 중복 집계하지 않는다. 원문/그림 권한도 구별한다.

읽은 범위는 서지/초록/전문 일부/전문 검토/방법·보충자료로 표시한다. 페이지를 열거나 URL을 확보한 사실만으로 전문 검토 완료라 하지 않는다.

| 평가 | 확인 |
|---|---|
| 직접성 | 근육·변형·집단·결과가 주장과 맞는가 |
| 측정 | 장기 MRI/초음파·근력·급성 EMG 구분 |
| 설계 | 배정·비교·운동량·기간·표본·결측 |
| 종합 | 중복·편향·이질성·추정 불확실성 |
| 적용 | 연령·성별·경험·건강·장비·범위 |
| 이해관계 | 연구비·장비/보충제 관계 |

미검토는 명시한다. 메타분석을 자동 최고 등급으로 두지 않는다. 전문 검토에서 필요 시 RoB/AMSTAR 등의 적용을 정한다.

주장 상태: 초록 기반 후보 / 검토된 주장 / 추론·제품 가설 / 상충·보류 / 대체됨. 과학적 확실성, OKF의 작성·검증 주체, 제품 승인 상태는 다르다.

출처 후보 → 추출 → 범위/한계 → 근거 지도 → 전문가 검토 → 공개 문구/정책 → 버전 → 관련 콘텐츠 갱신. 새 논문으로 즉시 추천을 바꾸지 않고 이유와 영향을 남긴다.
