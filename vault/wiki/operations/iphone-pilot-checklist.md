# iPhone 실사용 확인

[운영 앱](https://lightweight-training.pages.dev)을 홈 화면에서 연다. 설치·홈 화면 실행·로그인은 [CONV0020](../conversations/2026-10-04-020.md)에서 사용자 확인 완료다. 아래 운동/접근성/보존 과업은 아직 실제 기기 통과가 아니다. 기기/OS는 파일럿 표본이며 다른 사용자 지원을 제한하지 않는다.

## 다음 운동에서 확인할 순서

1. 로그인 계정과 사용자 설정을 확인하고, 수행한 운동의 세트·횟수·중량을 기록한다. 없는 수행을 실제 기록으로 꾸미지 않는다.
2. 저장 표시를 확인한 뒤 앱을 닫고 다시 연다. 해당 기록의 입력값·완료 상태·시작/종료 시각이 유지되는지 확인한다.
3. 설정의 ‘현재 프로필 백업’으로 파일 앱의 본인이 관리하는 위치에 저장한다. 개인 백업은 공개 vault/채팅/GitHub로 보내지 않는다.
4. 인터넷에 연결하여 ‘클라우드로 전송’을 누르고 전송 확인·최근 시각·대기 상태를 확인한다. 현재 전송은 수동이며 기기 저장 성공과 서버 전송 성공은 다르다.
5. 다른 저장소에서 로그인한 뒤 ‘클라우드 기록 불러오기’로 서버 기록을 먼저 조회한다. 적용 전 해당 기기의 기록을 백업하고 명시 교체 안내를 확인한다. 같은 browser 프로필을 새 기기 검증으로 기록하지 않는다. 동시 편집/서버 충돌 해결은 별도 과업이다.

보고에는 ‘어느 단계/정상 또는 오류/앱이 보인 메시지’만 필요하다. 계정 ID·이메일/비밀번호·토큰·수치/백업은 수집하지 않는다. 아직 수행하지 않았다면 not_run으로 유지한다.

## 실제 기기 과업표

| 과업 | 관찰할 결과 | 현재 |
|---|---|---|
| 홈 화면 설치/실행/로그인 | 설치된 앱에서 직접 로그인 | 사용자 보고 pass |
| 운동 기록→종료→재실행 | 값/상태/시각 보존 | not_run |
| 실제 운동 클라우드 전송/새 저장소 적용 | 서버 확인·명시 교체·기록 보존 | not_run |
| 오프라인 입력→재실행→재연결 | 준비된 앱에서 기기 저장, 연결 후 별도 전송 | not_run |
| 키보드/작은 화면/가로 | 입력/완료 버튼 가림·가로 넘침 없음 | not_run |
| 확대/VoiceOver | 입력 이름/순서/버튼/오류·초점 복귀 이해 가능 | not_run |
| 운동 중 잠금/재실행·휴식 타이머 | 저장 값/진행·타이머 기준 유지 | not_run |
| 대기 중 새 버전 | 진행 운동에서는 적용 보류, 안전한 적용 뒤 보존 | not_run |
| 종료 기록 삭제/복구 | 값/시각 유지·집계 제외/복귀 | desktop browser pass; iPhone not_run |
| 백업 파일 앱 저장/복원 | 동일 기록/삭제 표시·개인 저장 위치 | desktop browser pass; iPhone not_run |

오프라인 과업은 연결된 상태에서 앱을 한 번 준비한 뒤, 정상 수행 중 기록할 때 연결을 끊고 확인한다. 계정 만료 상태의 offline/Auth는 별도다. 실제 저장소 quota/eviction을 확인하려고 개인 기기의 기록/웹사이트 데이터를 삭제하거나 저장소를 고의로 채우지 않는다. 해당 stress 과업은 별도 시험 기기/복구 준비가 있는 환경에서 진행한다.

## 판정과 보류

각 결과는 기기/OS·앱 배포·확인 시각·방법(human report 또는 직접 관찰)을 연결해 새 이력에 기록한다. 가짜 desktop Chromium/WebKit·주입 quota·native IndexedDB와 실제 iPhone 과업을 합산하여 전체 G3 pass로 만들지 않는다. 신뢰한 서버 ACK 없이 전송을 완료로, 로컬 프로필 분리만으로 계정 A/B 접근 검증을 완료로 표시하지 않는다.

4주 파일럿은 실제 사용 관찰이 필요하다. 근거 설명/티어/추천의 전문·전문가·자산 검토와 운영 메일/복구·다기기 검증은 별도 관문이다. [남은 작업](../product/remaining-work.md)·[하네스](testing-harness.md)·[종료 기록 계약](ended-record-recovery.md).
