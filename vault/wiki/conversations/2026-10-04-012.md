# CONV-0012 컴포넌트 재감사와 후순위 3D

[사용자 원문](../../raw/conversations/2026-10-04-012.md).

**명시 요구:** Mantine 홈페이지를 다시 참고하고 collapse/dropdown·좌우 여백·반복 outline을 전반 수정한다. 페이지별 실제 화면 캡처로 확인한다. 운동별 자극부위 애니메이션에 3D 해부학 모델링을 포함하되 지금은 가능성 검토만 하고 후순위에 둔다. 이어서 PRD 잔여 작업을 순차 진행한다.

**구현 선택:** NativeSelect는 Mantine 컴포넌트였으나 펼친 목록은 브라우저 native였다. 이를 Mantine Select로 바꾸고 filled 입력·카드의 표면 계층, 내부 Accordion default/좌우16px·설명 간격·Drawer 헤더를 수정했다. 공식 FAQ의 separated 형태를 모든 중첩 카드에 복제하지 않고 공식 Accordion의 default 형태를 선택했다. 구체 여백/색상은 구현 판단이며 사용자 최종 디자인 승인이 아니다.

**검증:** 새로운 로컬4177 origin의 가짜 데이터로 다섯 페이지 수정 전/후와 세트 상세·편집창·선택창을 캡처하고 저장된 이미지를 직접 확인했다. 320/390/768/1440px ×5화면의 document overflow0. 55개 기존 검사·lint/build/format 통과. [화면별 보고서](../product/component-review.md)·[수집/실행](../../raw/research/2026-10-04-component-review.json). fullPage 캡처에서 fixed/sticky 영역 위치가 실제 viewport와 달라질 수 있어 관련 viewport 캡처로 보완했다. 실제 iPhone/Safari·Auth·자동 browser runner/CI는 별도다.

**후순위 제안:** FR-17/VIS-3D-01~03로 계획하고 첫 운동 MVP의 선행 조건으로 넣지 않는다. Web 3D는 기술적으로 가능하지만 자산의 근육 분리·rig·운동 clip·권한/해부학 검토가 필요하다. [검토](../product/anatomy-3d-feasibility.md). 라이브러리 설치·3D 구현·자산 구매/다운로드는 하지 않았다. 3D/식단/AI 사이의 상세 일정과 예산은 미정이다.

**다음 순차 구현:** HAR-02의 백업 재시도·프로필 전환 DOM 계약을 먼저 보강해 HAR-03 자동 E2E의 기초를 만든다. 검증 결과는 progress/backlog에 이어 기록하며 HAR/SYNC 전체를 미리 완료 처리하지 않는다.
