# CONV-0018

사용자는 “지금 직접 생성하겠습니다”라고 답했다. 이후 DB에서 등록 계정1개를 확인했다. 실제 Auth user 행 확인이며 browser 생성 과정을 직접 관찰하거나 비밀번호를 수집한 것이 아니다.

허용 목록 SQL 등록 시도는 자동 승인 검토가 대상 계정/SQL 방식의 명시 승인이 없다고 판단해 거부했다. 이후 허용 계정은0개로 확인했고, exact account/SQL 승인 질문이 pending이다. 승인 전 다른 connector/CLI로 우회하지 않는다.

[원문](../../raw/conversations/2026-10-04-018.md)·[확인](../../raw/research/2026-10-04-release-account-gate.json). 실제 로그인/전송·복원은 아직 확인하지 않았고 개인 UUID/email/password는 공개 vault에 보관하지 않는다.
