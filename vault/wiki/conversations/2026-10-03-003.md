# CONV-0003 PWA 채택과 언어·저장 논의

2026-10-03, Asia/Seoul. [원문](../../raw/conversations/2026-10-03-003.md) · [현재 PRD](../product/prd.md) · [CHG-0003](../../history/changes/CHG-0003.md).

사용자 선택: PWA로 진행. 질문: 추천 언어와 개인화 데이터 저장 방법. 언어·클라우드 저장·서비스 공급자는 사용자 선택 전이다.

의견: TypeScript를 주 언어로, React+Vite를 화면/빌드로 추천한다. 실제 운동 기록부터 IndexedDB/Dexie에 먼저 저장하고 Supabase Auth/PostgreSQL로 동기화하는 계정 구조를 우선 추천한다. 입력 시험은 로컬만으로 시작할 수 있다. [기술·저장 판단](../product/technology-data-storage.md).

이전 로그인 없는 한 기기 제안보다 실사용 계정 DB를 이번에 우선 추천하는 이유는 누적 개인화 기록과 기기 변경 복구다. 서버 동기화는 독립 백업과 다르며 전송 대기·중복·충돌·사용자 분리를 구현해야 한다. 클라우드에 개인 기록을 실제 저장하는 선택은 아직 미확정이다.

반영: PRD 0.2.0 → 0.2.1. PWA 채택과 기술 추천 구체화는 기존 기능/범위 내 PATCH로 기록. DEC-015~018, Q-13~15, 출처 SRC-022~027, TEC-001~006와 데이터/검증 상세 추가.

실제 앱 구현·패키지 설치·Supabase 프로젝트 생성·외부 업로드·계정 설정·배포는 수행하지 않았다. 문서 구조 검증과 앱/권한/동기화 검증을 구분한다.
