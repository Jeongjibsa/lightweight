# CONV-0016 Cloudflare 공식 설정

사용자가 공식 prompt 실행을 다시 요청했고 선택적 beta `cf`는 생략하도록 답했다. 기존 Wrangler4.147.0을 유지한다. 이번 작업은 개발 환경 설정이며 앱 배포·외부 리소스 생성 선택을 추가하지 않았다.

공식 prompt 전체를 다시 fetch했고 이전 수집본과 SHA256이 같았다. 공식 installer로 스킬16개를 갱신하고 각 SKILL.md를 확인했다. ~/.codex/config.toml의 MCP5개는 공식 URL과 enabled 상태가 일치해 기존 등록을 유지했다. installer의 PromptScript global 미지원 메시지와 Codex 설치 성공을 구분한다.

`codex mcp login cloudflare`가 exit0/성공을 반환했다. 현재 main MCP의 계정 읽기는 HTTP200, public docs 검색도 성공했다. 이전 broad OAuth 자동 검토 거부/만료 이력은 보존하며 이번 성공으로 main MCP의 pending 상태를 갱신한다. 브라우저 승인 동작은 직접 관찰·자동화하지 않았다. 특화 MCP3개와 Wrangler 인증은 각각 미검증이다.

PRD0.8.2는 인증 현황과 도구 선택의 PATCH다. [운영](../operations/cloudflare-setup.md) · [CHG-0017](../../history/changes/CHG-0017.md). 등록 도구 갱신에는 agent 재시작을 안내한다. 기존 앱 수정과 개인 Obsidian graph는 별도 작업으로 보존한다.
