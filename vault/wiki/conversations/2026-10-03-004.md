# CONV-0004 스택 합의와 배포·보안 의견

2026-10-03, Asia/Seoul. [원문](../../raw/conversations/2026-10-03-004.md) · [PRD](../product/prd.md) · [변경](../../history/changes/CHG-0004.md).

사용자: 이전 제안 스택이 적합하다는 동의, 배포 방식과 공개 웹 환경의 보안 우려에 대한 의견 요청. TypeScript·React/Vite·Dexie·Supabase 기본 스택 방향을 채택한다. 세부 인증/동기화 정책과 비용 지출까지 모두 승인한 것으로 기록하지 않는다.

의견: Cloudflare Pages에 PWA 화면을 배포하고 Supabase에서 계정·기록·서버 기능을 운영하는 안. 초대 계정·가입/익명 제한·서버 소유자 검사·비밀키 보관·preview/운영 분리·안전한 출력·직접 접근 시험을 제안한다. 사이트 전체 Access는 추가 선택. 이메일 코드/지인 초대에는 SMTP와 템플릿 조건 확인이 필요하다. [상세](../product/deployment-security.md).

반영: PRD 0.2.1 → 0.2.2. DEC-019~022, 질문 Q-16/17, 공식 자료 SRC-028~032·SEC-001~005, 기존 기술·데이터·검증·출처 노트의 상태와 제한 갱신.

호스트·도메인·운영 Access·로그인/메일·비용·계정 회수·보관 정책은 미정. 앱 구현·공개 배포·외부 데이터 업로드·실제 DB/보안 시험은 수행하지 않았다. 의견 요청을 외부 배포 요청으로 확장하지 않는다.
