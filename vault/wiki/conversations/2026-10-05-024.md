# CONV-0024

직전 질문은 운영 `training_private.valid_snapshot`의 준비된 optional-field SQL 적용 승인을 요청했다. 인간 사용자의 “승인할게. 작업 재개해.” 답변으로 이 함수 교체 범위를 명시 승인받았다. 자동 검토의 이전 거부는 다른 경로로 우회하지 않았으며 같은 MCP apply_migration으로 승인된 SQL을 적용했다. 다른 계정의 등록·RLS 확장·Google provider 설정 승인은 포함하지 않는다.

기존 snapshot과 메모·장비/가동범위·휴식 즐겨찾기·종목 세부 분류/별칭의 RPC 저장→조회·재시도 및 부정 입력/권한 28개를 synthetic transaction에서 검사해 모두 통과하고 rollback했다. 실제 본인 기록은 읽거나 수정하지 않았다. 함수 identity/owner/ACL·RLS/정책을 유지했다. main push와 Git 배포는 기존 지속 요청의 보류 작업으로 이어간다. 실제 Auth/본인 운동·기기/다버전·과학/파일럿 관문은 유지한다.
